# Stanford HIVDB input files

Download the high-quality filtered genotype-phenotype datasets from:

https://hivdb.stanford.edu/pages/genopheno.dataset.html

Place `PI_DataSet.txt`, `NRTI_DataSet.txt`, `NNRTI_DataSet.txt`,
`INI_DataSet.txt`, and `CAI_DataSet.txt` in this directory. See the package-root
`README.md` for checksums and complete experiment commands.
